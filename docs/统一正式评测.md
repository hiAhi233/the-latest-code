# EKAGen与MedADM的统一报告评测

日期：2026-11-11。此次仅评测已有生成报告，没有重新训练或重新生成报告。
按当前实验约定，只计算BLEU-1/2/3/4、METEOR、ROUGE-L，不增加CIDEr-D。

## 统一协议

- 模型：EKAGen MRI适配版最终distill，MedADM F0。
- 相同46个测试病例，按病例ID严格对齐；同例参考文本不一致直接报错。
- 只比较Findings；MedADM从findings/reference_findings字段取值，不混入Impression。
- 两边原始文本使用相同的小写化和正则分词（ekagen_regex_symmetric_v1），标点作为token。
- BLEU使用EKAGen包内pycocoevalcap的Bleu(4)，ROUGE使用其Rouge。
- METEOR使用同一meteor-1.5.jar、同一English paraphrase资源，Java CLI参数均为-l en -norm。
- 缺少Java或资源时明确失败，不用METEOR-lite替代。
- scorer代码、jar、paraphrase文件、输入文件、统一参考文本均保存SHA256。
- 新目录保存结果，拒绝覆盖已有输出；旧的模型权重、生成文本和指标文件保留。

这里的“统一”指定的是可复现的同一实现与预处理，并非声称所有论文都采用这套分词。
此前用本项目轻量分词重算的数值仍是历史记录，后续对比以本次协议为准，不能混用。

`scripts/evaluate_standard_reports.py` 为项目入口。只需要numpy、对应scorer源码和Java，
不加载模型、不调用GPU。原有nlg_metrics.py中的轻量指标保留供历史结果兼容；
论文比较应使用新入口，不把旧的meteor_lite写成METEOR。
